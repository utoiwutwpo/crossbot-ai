GPSR 合规检查器

skills/gpsr-compliance-checker/

把 EU 2023/988《通用产品安全法规》的上架检查清单交给 AI：识别产品是否属于 CE 类目，逐项核对欧盟责任人（欧代）、当地语言安全警示语、CE 标识、说明书与型号标识，并生成可直接粘贴进 listing 的多语言合规块。

  • 7 大 CE 类目自动识别（玩具/电子/纺织品/儿童用品等）
  • 欧盟 27 国 + 英国 → 警示语语言自动映射（DE/FR/IT/ES/NL/PL…）
  • 5 项法定缺失检测：欧代 / 警示语 / 说明书 / 型号 / CE 标识
  • 生成含欧代占位与当地语言警示语的可粘贴合规块
  • 内置 69 个安全词库（中英双语），差评安全事件预警同源
全网几乎零同类开源数据版 JSON 随附MIT
# 安装：复制到 Agent 的 skills 目录
git clone https://github.com/YOUR_ORG/crossbot-ai
cp -r crossbot-ai/skills/gpsr-compliance-checker \
      ~/.claude/skills/

# 然后对 AI 说：
"检查这个 listing 是否符合 GPSR：
 产品名 Kids Building Blocks，
 卖往德国和法国"

欧洲平台规则库

skills/eu-marketplace-rules/

13 个欧洲及欧美电商平台的上架规则速查：标题字数上限、必需语言、GPSR 合规要点、覆盖国家。写 listing 之前问一句 AI，避免「Allegro 忘了翻译成波兰语」「Otto 标题超字数被拒审」这类高频返工。

  • Amazon 欧洲站 + 美国站 / eBay / Cdiscount / Otto / Allegro / eMAG
  • TikTok Shop / Fruugo / Walmart / Kaufland / Zalando / bol.com
  • 每平台：标题字数 / 五点数量 / 搜索词上限 / 默认语言
  • 9 条高频踩坑点：EAN 唯一键、波兰语强制、zDirect 入驻审核…
  • 规则数据由线上引擎自动导出（platforms.json），永不过期
13 平台 · 持续更新中英双语规则卡MIT
# 安装
cp -r crossbot-ai/skills/eu-marketplace-rules \
      ~/.claude/skills/

# 然后对 AI 说：
"我要上 Allegro 和 Kaufland，
 标题分别能用几种语言、多少字符？
 生成前先按规则检查我的文案"

↑ 规则随 CrossBot 线上引擎同步更新，git pull 即最新
