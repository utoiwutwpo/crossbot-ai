## 定位一句话（先换脑子）

**「欧洲全平台 Listing 质量 + 合规引擎」——文案只是入口，合规块和语义评分才是付费理由。**

不在"AI 写文案"上与免费官方工具（Amazon 生成式Listing 等）正面竞争；
每一层产品都对着一个已被验证的竞品空位。

## 获客布局：用产品自己获客 ✅ 已实现

产品自身就是获客漏斗，四件免费资产：

1. **免费体检落地页** `/gpsr-check`（+PL/RO 语言版）—— 免注册直接查
2. **平台规则速查表** `/rules` —— 13 平台字数/语言/GPSR，SEO 长尾 + 社群引用素材
3. **开源 Skills** `/skills` —— MIT 免费，装进卖家自己的 AI，GitHub 引流
4. **免费版每天 5 次** —— 注册即用，无信用卡

动线：免费工具 → 游客体检 → 注册（UTM 归因）→ 免费版 → 升级（埋点全链路）。
